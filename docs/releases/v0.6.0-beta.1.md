# youtar_ttap 0.6.0-beta.1 — Windows x64 Beta

此文件記錄 2026-10-28（Asia/Kuala_Lumpur）的 Windows beta 發佈候選與驗證結果。公開狀態以 [GitHub Release](https://github.com/ruisa87not-star/youtar_ttap/releases/tag/v0.6.0-beta.1) 為準。

## 下載選擇

- `youtar_ttap-Tauri-Setup-0.6.0-beta.1-x64.exe`：較小的 Tauri 安裝檔，使用系統 Microsoft Edge WebView2 Evergreen；缺少 runtime 時需網路下載。
- `youtar_ttap-Setup-0.6.0-beta.1-x64.exe`：Electron 安裝檔，內附 Chromium。
- `SHA256SUMS.txt`：上面兩個安裝檔的 SHA-256。

兩種版本提供相同的排課與 PNG 選課指引，可並存。安裝後不需要 Node.js 或 Rust。請從開始功能表啟動所選版本。

## 本次更新

- 新增小型 Windows Tauri 版；保留 Web 與 Electron。
- 修正桌面內嵌 UTAR 登入的舊 HTTP 轉址；顯示登入與連線錯誤。
- 改善官方 Course Timetable Preview 表格匯入。
- 已確認衝突的未選課程自動排至清單底部，Clear 後恢復。
- 加入可自行部署的 Web 隔離登入代理與伺服器部署指南。桌面登入直接連接 UTAR，不需要部署該代理。

## 已知限制

- Beta 版本尚未簽章，Windows 可能顯示未知發行者／SmartScreen 提示；沒有自動更新。
- 真實 UTAR CAPTCHA 需由使用者輸入；本應用不提交選課，實際選課須在官方系統完成。
- Web 登入代理尚未在正式伺服器部署，真實 Web 登入及容器／TLS／DNS 驗證仍待部署時完成。
- 本次自動登入測試使用合成資料，不使用帳密檔案或自動處理 CAPTCHA。

## 安裝檔與校驗碼

候選目錄：release/0.6.0-beta.1/。兩個安裝檔的 ProductVersion 均為 0.6.0-beta.1，Authenticode 狀態為 NotSigned。Tauri 主 exe 為 4,395,008 bytes；系統共用 WebView2 不計入安裝檔大小。

| 檔案 | Bytes | SHA-256 |
| --- | ---: | --- |
| youtar_ttap-Setup-0.6.0-beta.1-x64.exe | 114,052,882 | 4273dfc78f5d61cc83fd44925ffbde289ab0bb5dea65e8ca4086ba10abd2fd5c |
| youtar_ttap-Tauri-Setup-0.6.0-beta.1-x64.exe | 2,247,379 | 6f0741b1055bb9c83374fb93966395c4f65393a00ee029f3581d4bcd443b53d7 |

Electron NSIS payload 內 76 檔與已測試 unpacked 產物逐檔雜湊一致。Tauri NSIS 內的 exe 與 build exe 大小相同，僅 offset 3071264–3071266 的 UNK→NSS 標記不同，其他 bytes 全同；這符合 [Tauri 官方 bundler patch／restore 程式](https://github.com/tauri-apps/tauri/blob/dev/crates/tauri-bundler/src/bundle.rs)。本輪直接從安裝檔解出的 exe 執行 6 項整合測試，並逐檔核對附帶授權；未修改任一出貨 binary。打包檢查記錄：logs/release-0.6.0-beta.1-artifact-inspection.log。

第一次嚴格 hash equality 檢查在 Tauri bundle marker 上失敗，已展示完整錯誤。後續確認恰為上述 3 bytes 的官方轉換，校驗其餘內容並直接驗證出貨程式；沒有修改產品程式以略過此差異。
